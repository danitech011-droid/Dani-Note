# Dani-Note: Your Premium Document Studio

Build a premium note-taking and document editing application called "Dani-Note".

IMPORTANT BRANDING:

I have attached the official Dani-Note logo. Use this exact image as the main brand identity throughout the application:

- App icon

- Login/signup screens

- Dashboard header

- Loading screen

- Favicon

- Navigation branding

The entire design system should be inspired by the logo:

- Blue and purple gradient accents

- Clean white workspace

- Modern professional look

- Smooth animations

- Premium productivity app feeling similar to Microsoft Word, WPS Office, Google Docs, and Notion

PRODUCT GOAL:

Create Dani-Note as a powerful document editor where users can write, organize, save, and manage their notes and documents.

CORE FEATURES:

1. User Authentication

- Sign up

- Login

- User profile

- Secure user accounts

2. Dashboard

Create a beautiful document management dashboard with:

- Recent documents

- All documents

- Search documents

- Create new document button

- Folders/categories

- Favorites

- Grid and list view

- Document sorting by date and name

3. Professional Document Editor

Create a Microsoft Word-style editor with:

- Document title

- Large writing canvas

- Rich text editing

- Bold, italic, underline

- Headings

- Font selection

- Font size control

- Text colors

- Highlighting

- Text alignment

- Bullet lists

- Numbered lists

- Undo and redo

- Copy/paste support

- Word count

- Autosave indicator

4. Document Management

Allow users to:

- Create documents

- Edit documents

- Rename documents

- Delete documents

- Duplicate documents

- Move documents into folders

- Favorite documents

- Search document content

5. Database and Storage

Connect to Supabase.

Create a document database with:

- id

- user_id

- title

- content

- folder_id

- created_at

- updated_at

- is_favorite

Enable automatic saving and real-time updates.

6. Advanced Word Features

Add:

- Tables

- Image insertion

- Links

- Page layout

- Headers and footers

- Page numbers

- Document templates

- Print support

7. Export and Sharing

Add:

- Export as PDF

- Export as DOCX

- Export as TXT

- Print documents

- Share documents with links

- Viewer and editor permissions

8. AI Writing Assistant

Add an AI assistant inside the editor with:

- Improve writing

- Fix grammar

- Rewrite text

- Summarize documents

- Generate ideas

- Continue writing

- Translate content

9. User Experience

Make the application:

- Fully responsive on desktop, tablet, and mobile

- Fast and smooth

- Accessible

- Modern with polished animations

- Easy for beginners but powerful for professionals

The final result should look and feel like a serious productivity application that can compete with Microsoft Word, WPS Office, and Google Docs while maintaining the unique Dani-Note identity.

Always use the attached Dani-Note logo as the official visual reference.
